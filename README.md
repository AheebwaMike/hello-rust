## Getting Started

### Prerequisites
- [Rust](https://www.rust-lang.org/tools/install) installed
- Cargo (comes with Rust)

### Running a project
```bash
cd 001_project_1/
cargo run
```

### Building a project
```bash
cd 001_project_1/
cargo build --release
```
