# Why I'm Learning Rust

*Date: September 2026*

## The pull

Rust kept showing up. In blog posts, in tooling I use, in conversations about "the next big language." Eventually curiosity won.

## What I expect to be hard

Being honest up front, so future me can look back and laugh (or nod):

- **Ownership and borrowing** — everyone warns about this. I believe them.
- **Lifetimes** — sounds like a different language entirely.
- **The borrow checker** — apparently it argues with you. A lot.
- **Async / concurrency** — I'll get there eventually.

## What I expect to enjoy

- `cargo` — the tooling already feels better than anything I've used.
- `Result` and `Option` — no more `null` surprises sounds wonderful.
- The compiler's error messages — I hear they're unusually helpful.

## What "success" looks like

Not "master Rust." More like:

- Build small CLI tools without fighting the language.
- Read other people's Rust code and mostly follow it.
- Understand *why* the borrow checker complains, not just how to silence it.

## A note to future me

If you're reading this months from now: did ownership actually break your brain? Which fear turned out to be overblown? Which one was worse than expected? Update this page with the truth.
