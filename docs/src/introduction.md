# Introduction

Welcome to *Towards becoming a Rustacean* — a personal log of my journey learning Rust.

This isn't a textbook. It's a trail of breadcrumbs: things I tried, things that broke, things that finally clicked. I'm writing it primarily so I can look back and see how far I've come. If it happens to help another beginner along the way, even better.

## Who this is for

- **Future me** — so I don't forget what confused me, and can measure progress.
- **Other Rust beginners** — especially anyone coming from another language and hitting the same walls.

## How to read this

- The **Journal** section is chronological and rough. Dated entries. Stream of consciousness.
- The **Guide** section is thematic and polished. Written only *after* I've actually understood something.
- The journal feeds the guide. When a theme repeats enough, it gets promoted.
